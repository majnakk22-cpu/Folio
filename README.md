# Folio

Основа книжного интерфейса для модов под **Minecraft 1.20.1 / Forge 47**: по задумке — замена Patchouli. Folio рисует
книгу-руководство и журнал в одном оформлении (тёмная книга на разворот из двух страниц, закладки, гиперссылки между главами,
иконки предметов в тексте, общие кнопки), но **не содержит ни предметов, ни текстов, ни содержимого**: предметы, названия,
главы и записи остаются в вашем моде. Сама по себе библиотека ничего не добавляет в игру.

## Что внутри (и что остаётся в вашем моде)

| В Folio | В вашем моде |
|---|---|
| Экран книги: оглавление → раздел → глава, гиперссылки, история «Назад», «Продолжить чтение», прогресс (`BookScreen`) | Предмет-книга и его открытие |
| Экран журнала: вкладки-категории, список записей, чтение, «???» у закрытых (`JournalScreen`) | Предмет-журнал, предметы-записки, их NBT и лут |
| Описание: `BookDefinition`, `JournalDefinition` и реестры `FolioBooks`, `FolioJournals` | Данные: главы, разделы, записи, категории, иконки, цвета |
| Хранение открытых записей в данных игрока, уведомление о новой записи, пакет «открыть журнал» (`FolioJournals`) | Когда открывать запись (события, добыча, бои) |
| Разметка текста (`FolioText`), кнопки (`FolioWidgets`), стандартная тема (`FolioTheme.DEFAULT`) | Все тексты в lang, своя тема: фон книги, цвета, вид кнопок |

## Быстрый старт

**1. Зависимость.** В `mods.toml` вашего мода:

```toml
[[dependencies.yourmod]]
    modId="folio"
    mandatory=true
    versionRange="[1.0.0,)"
    ordering="AFTER"
    side="BOTH"
```

**2. Описание данных** (в конструкторе мода: код выполняется и на клиенте, и на сервере):

```java
public static final ResourceLocation BOOK = new ResourceLocation("yourmod", "guide");
public static final ResourceLocation JOURNAL = new ResourceLocation("yourmod", "journal");

FolioBooks.register(BookDefinition.builder(BOOK)
        .langPrefix("guide.yourmod")            // ключи глав и разделов
        .title("gui.yourmod.guide.title")       // название на обложке
        .subtitle("gui.yourmod.guide.subtitle") // подпись на обложке
        .section("yourmod:some_item", 0xFF5BD35B) // раздел 0: иконка и цвет акцента
        .section("yourmod:other_item", 0xFF4FC3E8)
        .chapter("welcome", 0, "yourmod:some_item") // глава: id, номер раздела, иконка
        .chapter("tools", 0, "yourmod:other_item")
        .build());

FolioJournals.register(JournalDefinition.builder(JOURNAL)
        .langPrefix("journal.yourmod")
        .title("gui.yourmod.journal.title")
        .category("gui.yourmod.journal.cat.notes", "yourmod:note", 0xFFE8B84A)
        .entry("first_note", 0, "yourmod:note")   // запись: id, номер категории, иконка
        .build());
```

**3. Свои предметы** (в вашем моде, Folio их не даёт). Книга открывается на клиенте:

```java
public class GuideItem extends Item {
    public GuideItem(Properties p) { super(p); }

    @Override
    public InteractionResultHolder<ItemStack> use(Level level, Player player, InteractionHand hand) {
        if (level.isClientSide) {
            DistExecutor.unsafeRunWhenOn(Dist.CLIENT, () -> () -> FolioClient.openBook(YourMod.BOOK));
        }
        return InteractionResultHolder.sidedSuccess(player.getItemInHand(hand), level.isClientSide);
    }
}
```

Журнал открывается с сервера (Folio сам отправит игроку пакет с открытыми записями):

```java
// в use() предмета-журнала, на сервере:
FolioJournals.open(serverPlayer, YourMod.JOURNAL, null);   // null — без выбора, либо id записи, чтобы открыть её сразу
```

**4. Открывать записи** (на сервере, когда вам нужно):

```java
FolioJournals.unlock(serverPlayer, YourMod.JOURNAL, "first_note"); // true, если запись новая; игрок видит уведомление
FolioJournals.unlocked(serverPlayer, YourMod.JOURNAL);             // список открытых id
```

Записку-предмет (один предмет, запись в NBT) пишете сами: при ПКМ вызовите `unlock` и `open` для её записи,
название предмета берите из `def.langPrefix() + "." + id + ".title"`.

## Ключи lang

Книга с `langPrefix("guide.yourmod")`:

* `gui.yourmod.guide.title` и `.subtitle` — обложка (ключи вы задаёте сами);
* `guide.yourmod.section.N.title` и `.desc` — раздел N;
* `guide.yourmod.<глава>.title`, `.desc` (короткая подпись, около 18 символов), `.text` (разметка).

Журнал с `langPrefix("journal.yourmod")`: `journal.yourmod.<запись>.title` и `.text`. Названия вкладок-категорий — ключи из `category(...)`.
Общие надписи интерфейса (кнопки, счётчики, «???») уже есть в Folio на русском и английском (`folio.*`).

## Разметка текста

Строка начинается с `# ` — заголовок, `- ` — пункт списка, `> ` — врезка (совет). Пустая строка — отступ. Внутри строки:

| Запись | Результат |
|---|---|
| `**жирный**` | выделение |
| `[[id_главы\|текст]]` | кликабельная гиперссылка на главу той же книги |
| `{{item:modid:item_id}}` | иконка предмета с подсказкой при наведении |

Не используйте символ `%` в текстах (сломает форматирование перевода Minecraft).

## Тема: фон книги и кнопки

Оформление задаёт сам мод через `FolioTheme` и передаёт в `BookDefinition` / `JournalDefinition` методом `.theme(...)`.
Всё, что не задано, остаётся как в стандартном оформлении Folio, так что менять можно только нужное; книги без `.theme(...)`
выглядят как раньше. Тема — только данные (цвета и ссылки на текстуры), её можно создавать в конструкторе мода на любой стороне.

Цвета — `0xAARRGGBB`; без альфы (`0xRRGGBB`) цвет считается непрозрачным.

```java
FolioTheme theme = FolioTheme.builder()
        .skin(new ResourceLocation("yourmod", "textures/gui/guide_book.png"))   // фон разворота
        .title(0xFFC0392B).heading(0xFFC0392B)                                   // название и заголовки глав
        .text(0xFFE6D8D8, 0xFFFFFFFF)                                            // обычный и **жирный** текст
        .link(0xFFFF8A65, 0xFFFFCCBC)                                            // гиперссылки и «Назад»
        .arrow(0xFF4A2A2A, 0xFFC0392B, 0xFF241414, 0xFF3A1E1E, 0xFFD9B8B8, 0xFFFFFFFF) // стрелки листания
        .tab(0xFF120808, 0xFF1E1010, 0xFF3A1E1E, 0.30F)                          // закладки
        .row(0xFFE6D8D8, 0xFFFFFFFF, 0xFF9A8080, 0xFFC0392B)                     // строки разделов и глав
        .build();

BookDefinition.builder(BOOK).theme(theme) /* ... */ .build();
JournalDefinition.builder(JOURNAL).theme(theme) /* ... */ .build();   // одну тему можно отдать и книге, и журналу
```

### Фон книги

Один из трёх вариантов:

| Вариант | Как задать |
|---|---|
| Скин по умолчанию | ничего не задавать |
| Своя текстура | `.skin(rl)` — 512×256: разворот 312×196 в левом верхнем углу, эмблема обложки 32×32 в точке (320, 0). Текстура другого размера с теми же пропорциями (например 1024×512 для чёткого фона): `.skin(rl, 1024, 512)`. Разворот лежит не в углу: `.skinRegion(u, v, w, h)` |
| Без текстуры, заливка цветом | `.panel(рамка, кант, страница, контур страницы, корешок)` |

Зона текста не зависит от фона: две страницы по 132×136 пикселей (левая — от x=18, правая — от x=162, обе от y=34).
Рисуйте свою текстуру так, чтобы текст ложился на страницы, а внизу оставалось место для стрелок (нижние ~24 пикселя).

Вращающаяся эмблема на обложке по умолчанию берётся из скина (справа от разворота). Другая текстура: `.emblem(rl, u, v, размер, texW, texH)`;
убрать совсем: `.noEmblem()`. При `.panel(...)` эмблемы нет, пока не задана своя.

Короткая запись `.skin(rl)` у `BookDefinition.Builder` и `JournalDefinition.Builder` работает по-прежнему: заменяет только текстуру фона.

### Цвета текста

| Метод | Что красит |
|---|---|
| `.title(c)` | название на левой странице |
| `.heading(c)` | заголовки глав и линия под ними |
| `.text(обычный, жирный)` | основной текст и `**выделение**` |
| `.muted(c)` | счётчики страниц, подписи |
| `.subtitle(c)` | подпись на обложке |
| `.link(обычная, при наведении)` | гиперссылки `[[...]]`, «Назад», «Продолжить чтение» |
| `.note(полоса, текст)` | врезки `> ...` |
| `.bullet(c)` | маркеры списка |
| `.progressBar(заливка, фон, контур)` | полоска прогресса на обложке |
| `.locked(акцент, недоступный текст)` | закрытые записи журнала, недоступные текстовые кнопки |

### Кнопки

| Метод | Что настраивает |
|---|---|
| `.arrow(контур, контур при наведении, заливка, заливка при наведении, значок, значок при наведении)` | стрелки листания |
| `.arrowDisabled(контур, заливка, значок)` | недоступная стрелка |
| `.tab(контур, невыбранная, выбранная, доля акцента)` | закладки разделов; доля акцента — сколько цвета раздела подмешать к выбранной (0…1) |
| `.contentsTab(c)` | цвет закладки «Оглавление» (в журнале — «Все») |
| `.row(название, название при наведении, шеврон, метка «прочитано»)` | строки-ссылки (разделы, главы, записи журнала) |
| `.rowDivider(argb)` | пунктир под строкой (`0` — убрать) |
| `.rowHighlight(сила подсветки 0–255, акцентная полоска слева)` | подсветка строки при наведении |

Акцентный цвет каждого раздела и категории по-прежнему задаётся в самих данных (`.section(...)`, `.category(...)`).

**Спрайты вместо заливки.** Для стрелок, закладок и строк можно задать текстуру, растягиваемую по 9 частям:

```java
FolioTheme.Sprite arrows = FolioTheme.sprite(tex, u, v, w, h, border, texW, texH);
theme.arrowSprite(arrows).tabSprite(tabs).rowSprite(rows)
```

Состояния лежат в текстуре друг под другом, каждое высотой `h`: `v` — обычное, `v + h` — наведение, `v + 2h` — недоступная
(только у стрелок). У закладок «выбрана» рисуется как состояние наведения. `border` — ширина углов, которые не растягиваются.
Значки, текст и шевроны рисуются поверх спрайта; если спрайт уже содержит подсветку, отключите её: `.rowHighlight(0, false)`.

### Общая тема для нескольких книг

`theme.toBuilder()` возвращает билдер с теми же значениями: можно взять базовую тему мода и поменять пару цветов для журнала.

## Сборка

Folio — самостоятельный проект Gradle. Нужны JDK 17 и Gradle 8.x:

```
gradle build
```

Готовый мод: `build/libs/folio-1.0.0.jar`. Его кладут в папку `mods` рядом с модами, которые от него зависят.

## Подключение к проекту мода

Два способа, оба используют `fg.deobf`, потому что собранный jar содержит продакшн-имена.

**1. Файл в папке `libs/`** (проще всего). Скопируйте `folio-1.0.0.jar` в папку `libs/` проекта мода и добавьте в `build.gradle`:

```groovy
repositories {
    flatDir {
        dirs 'libs'
        content { includeGroup 'dev.folio' }
    }
}
dependencies {
    implementation fg.deobf("dev.folio:folio:1.0.0")
}
```

**2. Локальный Maven.** В проекте Folio выполните `gradle publishToMavenLocal`, затем в проекте мода:

```groovy
repositories {
    mavenLocal {
        content { includeGroup 'dev.folio' }
    }
}
dependencies {
    implementation fg.deobf("dev.folio:folio:1.0.0")
}
```

В `mods.toml` мода добавьте зависимость от `folio` (см. «Быстрый старт», шаг 1). Оба способа я не проверял в сборке.
